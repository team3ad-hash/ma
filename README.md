# לידים מול הוצאת פרסום — צוות 3 מערכות מיגון

דשבורד סטטי (`dashboard/leads-vs-spend.html`) שמצליב בין הוצאת הפרסום הממומן
ב-Facebook Ads Manager (חשבון "צוות 3 מערכות מיגון") לבין לידים וסגירות בפועל
מקבצי ה-CRM: טפסי יצירת קשר באתר ושיחות טלפון למספר המעקב (מאסקיו).

פתחו את `dashboard/leads-vs-spend.html` בדפדפן כדי לצפות בדשבורד.

## מה בפנים

- **הוצאת פרסום** — פילוח הוצאה לפי סוג קמפיין (מכירות / גיוס עובדים / אחר), מגמה
  חודשית, והקמפיינים המובילים בהוצאה בערוץ המכירות (מקור: Facebook Ads Manager, ינואר–אוגוסט 2026).
- **לידים מה-CRM** — לידים וסגירות לפי ערוץ קליטה (טפסי אתר / שיחות טלפון) ולפי
  מקור UTM (פייסבוק / גוגל / אתר אורגני / לא ידוע).
- **הצלבה ופער מדידה** — השוואה בין לידים לפי מדידת הפיקסל של מטא לבין לידים
  שניתן לשייך בפועל ל-CRM דרך UTM, כולל הקמפיינים שכן זוהו והמלצות לסגירת הפער.

מתודולוגיה מלאה, הגדרות ומקורות נתונים מפורטים בתחתית הדשבורד עצמו.
