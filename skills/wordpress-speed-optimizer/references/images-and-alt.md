## 1. איך למצוא תמונות בעייתיות
- PageSpeed Insights: "Properly size images", "Serve images in next-gen formats",
  "Efficiently encode images", "Largest Contentful Paint element".
- DevTools → Network → Img, מיון לפי Size. כל תמונה מעל ~200KB באתר תדמית היא חשודה.
- ספריית המדיה: קבצים של 3–8MB ישירות ממצלמה/טלפון, PNG לצילומים, תמונות 4000px+.
- תמונות רקע של Elementor/Divi (CSS background) — לא נכנסות ל-srcset ולא ל-lazy load
  של וורדפרס; לרוב צריך להחליף לווידג'ט תמונה או להעלות גרסה קטנה ייעודית למובייל.

## 2. פורמטים ואיכות דחיסה
| סוג תמונה | פורמט מומלץ | איכות |
|---|---|---|
| צילום / תמונת מוצר | WebP (או AVIF) | WebP 75–82, AVIF 50–63 |
| גרפיקה עם שקיפות | WebP lossless / PNG מכווץ | — |
| לוגו / אייקונים | SVG (מסונן — SVG עלול להכיל סקריפט) | — |
| אנימציה | MP4/WebM במקום GIF | — |

- WebP חוסך בדרך כלל 25–35% מול JPEG באיכות דומה; AVIF חוסך עוד, אבל הקידוד איטי יותר.
- וורדפרס 5.8+ תומך ב-WebP, 6.5+ ב-AVIF (בתנאי ששרת ה-Imagick/GD תומך).
- הסר EXIF/GPS — חוסך משקל וגם מגן על פרטיות (מיקום צילום).
- דחיסה "lossy" ברמה בינונית כמעט תמיד בלתי מורגשת בעין; "glossy"/lossless רק לצילום מוצר
  באיכות גבוהה במיוחד.

## 3. מידות ו-srcset
- גודל מקסימלי להעלאה: 1920–2560px ברוחב לתמונות full-width, 1200px לתמונות בתוך תוכן.
- וורדפרס מקטין אוטומטית קבצים מעל 2560px (`big_image_size_threshold`); אפשר להנמיך ל-1920.
- וודא שהתבנית מוציאה `srcset` ו-`sizes` — בלי זה המובייל מוריד את הגרסה הגדולה.
- גדלי תמונות לא בשימוש (תוספים ותבניות רושמים 10+ גדלים) מנפחים את השרת; אפשר לבטל
  עם `intermediate_image_sizes_advanced` (ראה code-snippets) ואז Regenerate Thumbnails.

## 4. תמונת ה-LCP
אלמנט ה-LCP הוא בדרך כלל תמונת ה-hero/באנר או תמונת המוצר הראשית.
- **לא** lazy-load (`loading="eager"`).
- `fetchpriority="high"` על התמונה.
- preload ב-`<head>` אם היא תמונת רקע CSS או נטענת מאוחר (עם `imagesrcset`).
- שקול מידות קטנות יותר / תמונה ייעודית במובייל.
- וורדפרס 6.3+ מוסיף fetchpriority אוטומטית לתמונה הראשונה בתוכן — אבל לא תמיד מזהה נכון
  בבוני עמודים. בדוק בקוד המקור.

## 5. Lazy loading ו-CLS
- `loading="lazy"` לכל התמונות מתחת לקפל (native, וורדפרס מוסיף אוטומטית).
- כל `<img>` חייב `width` ו-`height` (או `aspect-ratio` ב-CSS) כדי למנוע קפיצות (CLS).
- iframe של YouTube/מפות: lazy-load או facade (תמונה ממוזערת שמחליפה ל-iframe בלחיצה) —
  קיים ב-WP Rocket, LiteSpeed, Perfmatters, FlyingPress.
- סליידרים ב-hero (Revolution, Elementor carousel) הם אחד מגורמי ה-LCP/CLS הגרועים —
  המלץ להחליף לתמונה סטטית.

## 6. תוספים מומלצים
בחר **אחד**:
- **LiteSpeed Cache (QUIC.cloud)** — אם השרת LiteSpeed; כולל דחיסה, WebP/AVIF ו-lazy load.
- **ShortPixel** / **Imagify** / **EWWW** — דחיסה + המרה + הגשת WebP (דרך `<picture>` או
  rewrite rules). הגדרות מומלצות: Lossy, שמירת מקור (backup), Resize ל-1920–2560,
  הסרת EXIF, יצירת WebP/AVIF, Bulk optimize לספרייה הקיימת.
- תוספי CDN תמונות (Jetpack/Bunny Optimizer/Cloudflare Polish) — חלופה כשאין גישה לשרת.

## 7. תגיות ALT

### למה זה חשוב
- **נגישות** — קוראי מסך מקריאים את ה-ALT; בישראל זה גם חלק מדרישות תקן הנגישות (ת"י 5568 / WCAG 2.0 AA).
- **SEO** — גוגל משתמש ב-ALT להבנת התמונה (Google Images) והקשר העמוד.
- ALT לא משפיע ישירות על מהירות, אבל הוא חלק סטנדרטי מ-audit התמונות ומצוין ב-Lighthouse (Accessibility).

### כללי כתיבה
1. תאר מה רואים **ומה התפקיד בהקשר** של העמוד. אותה תמונה יכולה לקבל ALT שונה בעמודים שונים.
2. קצר ומדויק: עד ~125 תווים, משפט אחד.
3. בלי "תמונה של" / "image of" — קורא המסך כבר מודיע שזו תמונה.
4. בשפת העמוד (עמוד עברי → ALT בעברית).
5. מילת מפתח רק אם היא מתארת את התמונה באמת. בלי רשימות מילים (keyword stuffing).
6. תמונה שהיא קישור/כפתור — תאר את **היעד/הפעולה** ("חזרה לעמוד הבית", לא "לוגו").
7. תמונה עם טקסט (באנר מבצע) — ה-ALT כולל את הטקסט החשוב שבתמונה.
8. דקורטיבית בלבד (קווים, רקעים, אייקון ליד טקסט שכבר אומר אותו דבר) — `alt=""` ריק, לא חסר.
9. מוצרים ב-WooCommerce: שם מוצר + מאפיין מבדיל (צבע/זווית/שימוש) — כדי שבגלריה כל תמונה תהיה שונה.

### דוגמאות
| הקשר | רע | טוב |
|---|---|---|
| עמוד שירות התקנת מצלמות | `IMG_4432.jpg` | `טכנאי מתקין מצלמת אבטחה על חזית בית פרטי` |
| חנות — גלריית מוצר | `מחבת מחבת קנה מחבת זולה` | `מחבת נון-סטיק 28 ס"מ בצבע אפור, מבט מלמעלה` |
| לוגו בהדר (מקשר לבית) | `לוגו` | `צוות 3 מערכות מיגון — לעמוד הבית` |
| באנר מבצע | `באנר` | `מבצע חורף: 20% הנחה על מערכות אזעקה עד 30.11` |
| קו מפריד דקורטיבי | `קו` | `alt=""` |

### תהליך עבודה מול האתר
1. שלוף רשימת מדיה (MCP: `wp_get_media`, או ייצוא / WP-CLI:
   `wp post list --post_type=attachment --fields=ID,post_title,guid --format=csv`
   ואז `wp post meta get <ID> _wp_attachment_image_alt`).
2. סנן: ALT חסר, ALT שהוא שם קובץ, ALT כפול בין תמונות.
3. לכל תמונה — הבן את ההקשר (באיזה עמוד/מוצר היא מופיעה) ונסח הצעה. אם אפשר לראות
   את התמונה עצמה, תאר לפיה ולא רק לפי שם הקובץ.
4. הצג טבלה לאישור המשתמש: `ID | קובץ | עמוד | ALT נוכחי | ALT מוצע`.
5. אחרי אישור — עדכן (`wp_update_media` עם `alt_text`, או
   `wp post meta update <ID> _wp_attachment_image_alt "..."`).
6. שים לב: תמונות שכבר הוטמעו בבלוק/בתוכן פוסט שומרות עותק של ה-ALT בתוך ה-HTML.
   עדכון בספריית המדיה לא מתעדכן שם — צריך לעדכן גם את התוכן (או בוני עמודים כמו
   Elementor ששומרים ALT בהגדרות הווידג'ט).
