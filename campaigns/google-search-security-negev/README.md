# Google Search — מאבטחים חמושים בנגב

קמפיין Search נפרד לכל משרה (₪80 ליום כל אחד). כל המודעות מפנות לדף המשרה של הקמפיין, עם UTM ב-Final URL.

| קמפיין | משרה | utm_campaign |
|---|---|---|
| SRC \| משרה 124651 \| מאבטחים עידן הנגב | #124651 | search_job124651_idan_hanegev |
| SRC \| משרה 124655 \| מאבטחים נאות חובב | #124655 | search_job124655_neot_hovav |

- `output/google-ads-editor-import.csv` — קובץ אחד לייבוא ל-Google Ads Editor (הקמפיינים מיובאים במצב **Paused**).
- `output/editor-csv/01…07_*.csv` — אותו תוכן מפוצל לפי סוג ישות (גיבוי).
- `output/brief-search-security-negev.xlsx` — בריף מלא: סקירה, מבנה, UTM, מילות מפתח, שליליות, RSA, נכסים, מעקב, צ'קליסט, מדריך ייבוא.
- `build.py` — מקור כל התוכן; לעריכה: לשנות ולהריץ `python build.py` (כולל ולידציה של אורכי תווים).
