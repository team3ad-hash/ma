# קריאייטיב וקופי — מסגרות ומפרטים

## מסגרות כתיבה

- **PAS** — Problem → Agitate → Solution. מצוין לשירותים שפותרים כאב.
- **AIDA** — Attention → Interest → Desire → Action.
- **BAB** — Before → After → Bridge (המוצר הוא הגשר).
- **4U לכותרות** — Useful, Urgent, Unique, Ultra-specific.
- **התנגדות → תשובה** — "חושבים שזה יקר? ההתקנה מתחילה מ-..."

כללים: ספציפיות מנצחת ("התקנה תוך 48 שעות" > "שירות מהיר"); מספרים, אזור גאוגרפי, הוכחה
חברתית (מספר לקוחות, דירוג, שנות ניסיון); CTA אחד ברור; התאמת מסר בין מודעה לדף נחיתה.

## Google — RSA (Responsive Search Ads)

- עד 15 כותרות (30 תווים) ו-4 תיאורים (90 תווים). כתוב לפחות 10 כותרות שונות באמת.
- תמהיל כותרות: 3–4 עם מילת המפתח, 2–3 יתרונות, 2 הוכחה/אמון, 2 הצעה/מחיר, 1–2 CTA, 1 מותג.
- הצמדה (Pin) רק כשחייבים (רגולציה/מותג) — מוריד גמישות.
- Assets חובה: Sitelinks (4+), Callouts (4+), Structured snippets, Call, Location, Image, Lead form לפי הצורך.
- **ספירת תווים בעברית**: כל אות = תו; ניקוד לא מומלץ. בדוק אורך לפני מסירה.

## Meta — מבנה מודעה

- **Primary text**: 125 תווים ראשונים נראים לפני "עוד" — שם ה-hook. 2–3 גרסאות (קצרה / סיפורית / רשימה).
- **Headline**: ~40 תווים, הבטחה או הצעה.
- **Description**: אופציונלי, לא תמיד מוצג.
- **CTA button**: Learn More / Get Quote / Send WhatsApp Message / Call Now / Sign Up.
- וידאו: Hook ב-0–3 שניות, הצגת בעיה, פתרון, הוכחה, CTA. 15–30 שניות לרוב מספיק.
- טקסט על התמונה: מינימלי וקריא במובייל.
