# KPIs, אבחון, תקציב ודוחות

## נוסחאות יסוד

- CTR = Clicks / Impressions · CPC = Cost / Clicks · CPM = Cost / Impressions × 1000
- CVR = Conversions / Clicks · CPA (CPL) = Cost / Conversions
- ROAS = Revenue / Cost · POAS = Gross profit / Cost
- **CPA = CPC / CVR = CPM / (1000 × CTR × CVR)** — זה הבסיס לכל אבחון.
- **עלות לעסקה (CAC אמיתי)** = Cost / סגירות ב-CRM = CPL / שיעור סגירה.

## חישוב CPA יעד (Break-even ויעד)

```
רווח גולמי לעסקה  = שווי עסקה ממוצע × שולי רווח (או LTV × שולי רווח)
CAC מקסימלי       = רווח גולמי לעסקה × (1 − יעד רווח מהעסקה)
CPL מקסימלי       = CAC מקסימלי × שיעור סגירה (ליד→לקוח)
```
דוגמה: עסקה 8,000 ₪, רווח גולמי 40% = 3,200 ₪; רוצים להשאיר 50% → CAC מקס' 1,600 ₪;
סגירה 10% → **CPL מקסימלי 160 ₪**. מכאן נגזר tCPA, תקציב ותחזית.

## עץ אבחון — "הביצועים ירדו"

1. **ודא שהבעיה אמיתית**: טווח תאריכים זהה באורכו, אותם ימי שבוע, חג/אירוע? עיכוב ייחוס
   (ימים אחרונים תמיד חסרים המרות)? שינוי בהגדרות המרה?
2. **מדידה**: ירידה חדה ופתאומית ב-0 המרות = כמעט תמיד תג/פיקסל/טופס שבור. בדוק לידים ב-CRM.
3. **פרק את ה-CPA**: איזה רכיב השתנה — CPM / CPC, CTR, או CVR?
   - **CPM/CPC ↑** → תחרות, עונתיות, קהל צר, Quality/Ad Rank ירד, שינוי בידינג.
   - **CTR ↓** → שחיקת קריאייטיב, שינוי בשאילתות/קהל, מתחרה עם הצעה טובה יותר.
   - **CVR ↓** → דף נחיתה (שינוי? איטי? שבור במובייל?), הצעה, איכות תנועה, מדידה.
4. **איפה**: פלטפורמה → קמפיין → סט/קבוצה → מודעה/מילה → מכשיר/מיקום/גאו. מצא את הרכיב
   שמסביר את רוב השינוי (Contribution analysis), לא את זה עם השינוי באחוזים הכי גדול.
5. **מה השתנה בחשבון**: Change history / activity logs — שינויי תקציב, יעד, קריאייטיב, הגדרות.
6. **חיצוני**: מתחרים (Auction insights, Ads Library), שוק, עונתיות, אירועים.

## הקצאת תקציב בין פלטפורמות

- Search (גוגל) קודם — לוכד ביקוש קיים בכוונה גבוהה, עד שה-IS גבוה וה-CPA השולי מתחיל לעלות.
- מטא — יוצר ביקוש, נפח גדול, CPL לרוב נמוך יותר אך איכות משתנה; חובה לשפוט לפי CRM.
- הקצה לפי **CPA שולי** (עלות ההמרה הבאה), לא ממוצע. הזזת תקציב בצעדים, בדיקה אחרי שבוע–שבועיים.
- תקציב מינימלי מעשי: לכל קמפיין/סט — שיאפשר לפחות ~10–20 המרות בחודש (גוגל) / להתקרב ל-50 בשבוע (מטא);
  אם התקציב לא מאפשר — אחד.

## תחזית

תן תמיד **טווח** (שמרני / סביר / אופטימי) עם ההנחות: CPC/CPM, CTR, CVR, שיעור סגירה.
לעולם אל תבטיח תוצאות. הדגש ש-4–6 השבועות הראשונים הם תקופת למידה.

## מבנה דוח ביצועים (שבועי/חודשי)

1. **תקציר מנהלים** (3–5 שורות): הוצאה, לידים/מכירות, CPA/ROAS מול יעד ומול תקופה קודמת,
   התובנה המרכזית, ההחלטה הנדרשת.
2. **טבלת KPIs**: הוצאה, חשיפות, קליקים, CTR, CPC, המרות, CVR, CPA, (ערך, ROAS) — לכל פלטפורמה וסה"כ,
   עם Δ% מול תקופה קודמת.
3. **הצלבה מול CRM**: לידים לפי מקור, לידים איכותיים, סגירות, עלות לעסקה.
4. **מה עבד / מה לא** — לפי קמפיין, קריאייטיב, מילות מפתח.
5. **פעולות שבוצעו** בתקופה.
6. **תוכנית לתקופה הבאה** + ניסויים מתוכננים.

כשמבקשים דוח כקובץ — השתמש בסקיל המתאים (pptx/xlsx/docs) או דשבורד HTML, ושמור על מבנה זה.
