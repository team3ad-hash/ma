# צ'קליסט אודיט חשבון

דרג כל ממצא: 🔴 קריטי (כסף נשרף / מדידה שבורה) · 🟠 חשוב · 🟢 שיפור.
הצג בסוף טבלת ממצאים ממוינת לפי השפעה, עם הערכת "כסף על השולחן" כשאפשר (למשל הוצאה על
מונחי חיפוש לא רלוונטיים ב-30 יום).

## 1. מדידה (תמיד ראשון)
- [ ] האם יש המרה ראשית אחת ברורה? המרות משניות מסומנות כ-Secondary?
- [ ] כפילויות (פיקסל + GA4 import + תג ישיר סופרים את אותו ליד)?
- [ ] Enhanced Conversions (Google) / CAPI + dedup + EMQ (Meta)?
- [ ] שיחות ווואטסאפ נמדדים?
- [ ] האם מספר ההמרות בפלטפורמה ≈ מספר הלידים ב-CRM? פער >30% = בעיה.
- [ ] UTM עקביים בכל המודעות? GCLID נשמר בטפסים?
- [ ] האם איכות/סגירות מוחזרות לפלטפורמות (Offline conversions / Conversion Leads)?

## 2. אסטרטגיה ותקציב
- [ ] CPA יעד מוגדר ונגזר מכלכלת היחידה?
- [ ] חלוקת תקציב לפי ביצועים שוליים (Marginal CPA) ולא לפי הרגל?
- [ ] קמפיינים מוגבלים בתקציב שמניבים טוב / קמפיינים שמוציאים בלי תוצאה?
- [ ] מותג מופרד מגנרי (גוגל) כדי לא לעוות CPA?

## 3. מבנה
- [ ] Google: פיצול-יתר (Ad groups עם מילה אחת וללא נתונים) או ערבוב כוונות?
- [ ] Meta: יותר מדי סטים קטנים ב-Learning limited? חפיפת קהלים?
- [ ] מטרות/אירועי אופטימיזציה נכונים?

## 4. טרגוט ותנועה
- [ ] Google: Search terms — הוצאה על שאילתות לא רלוונטיות? רשימות שליליות?
- [ ] התאמות מיקום: "Presence" (נמצאים באזור) ולא "Presence or interest"?
- [ ] Search Partners / Display Expansion פועלים בלי בקרה?
- [ ] PMax: Brand exclusions, החרגות מיקומים, איכות לידים?
- [ ] Meta: Audience Network / מיקומים עם לידים באיכות נמוכה?

## 5. בידינג
- [ ] אסטרטגיית הבידינג מתאימה לנפח ההמרות?
- [ ] tCPA/tROAS ריאליים (לא נמוכים מדי כך שהקמפיין "חונק")?
- [ ] שינויים תכופים מדי שמאפסים למידה (בדוק Change history / `ads_account_get_activity_logs`)?

## 6. קריאייטיב ומודעות
- [ ] Google: RSA עם Ad strength "Good"+; assets מלאים?
- [ ] Meta: מספיק מגוון קריאייטיב? Frequency? מודעות ישנות שחוקות?
- [ ] מודעות שנדחו / מוגבלות?

## 7. דף נחיתה
- [ ] מהירות מובייל (LCP < 2.5s), טופס קצר, חיוג/וואטסאפ בלחיצה, מסר תואם למודעה.
- [ ] אמון: המלצות, לוגואים, אחריות, כתובת/טלפון.

## 8. תפעול
- [ ] זמן תגובה ללידים? (הגורם הגדול ביותר לשיעור סגירה שאינו בשליטת המדיה — אבל משפיע על ה-ROI).
- [ ] משוב איכות מהמכירות חוזר למנהל הקמפיינים?
