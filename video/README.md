# סרטון גיוס · מאבטחים חמושים · צומת מסמיה (משרה 123088)

סרטון של 30 שניות לקמפיין **Google Demand Gen**, לגיוס לוחמים משוחררים (שירות מלא, רובאי 03 ומעלה ותעודת לוחם).

**הקונספט:** "השרטוט של לוחם". כל הסרטון הוא גיליון שרטוט טכני אחד, והמצלמה נעה בו ברציפות, בלי קאט אחד. היא עוברת בין "פרטי שרטוט" (תחנות):
דרישות, תוך מעבר על שרטוט נשק וסרגל רובאי; תוכנית אתר של תחנת הכוח, עם סיור ממונע, משאיות בשער וקו גדר; מד שכר; תג קורס מתקדם ב׳; שעון משמרות 24/7.
בסוף המצלמה מתרחקת וחושפת את כל הגיליון, ואז נכנסת ל־Title Block, שבו מופיעים הקריאה לפעולה וחותמת "מתאימים".

| קובץ | יחס | שימוש ב־Demand Gen |
|---|---|---|
| `out/team3_guard_16x9.mp4` | 1920×1080 | YouTube In-Stream / In-Feed |
| `out/team3_guard_9x16.mp4` | 1080×1920 | YouTube Shorts |
| `out/team3_guard_1x1.mp4` | 1080×1080 | Discover / Gmail / In-Feed |

אודיו: קריינות בעברית (ElevenLabs, הקול Nimrod), מוזיקה מקורית (ElevenLabs Music) ועיצוב סאונד פרוצדורלי (`audio/sfx.py`). הוויש נגזר ממהירות המצלמה. הכל ממוקסס ל־‎-14 LUFS. הטקסט על המסך מכסה את כל הקריינות, כך שהסרטון עובד גם בצפייה ללא קול.

## טקסטים מוצעים למודעה

**כותרות (עד 40 תווים)**
- סיימתם שירות קרבי? ₪68–75 לשעה
- דרושים מאבטחים חמושים · צומת מסמיה
- רובאי 03+? יש לנו משרה בשבילכם
- משרה מועדפת + בונוס עד ₪10,000
- לוחמים משוחררים: ₪68–75 לשעה

**כותרת ארוכה (עד 90 תווים)**
- מאבטחים חמושים לתחנת כוח בהקמה ליד צומת מסמיה · ₪68–75 לשעה · משרה מועדפת

**תיאורים (עד 90 תווים)**
- לוחמים משוחררים עם רובאי 03 ומעלה ותעודת לוחם. הסעות, ארוחות וקרן השתלמות מהיום הראשון.
- בונוס עד ₪10,000 לבעלי קורס מתקדם ב׳ בתוקף. משמרות בוקר/ערב/לילה. השאירו פרטים עכשיו.
- קורס הכשרה של 8 ימים, סטודנטים מוזמנים. משרה מועדפת לחיילים משוחררים.

**קריאה לפעולה:** "הגשת בקשה" או "הרשמה", עם טופס לידים (Lead Form): שם, נייד, יישוב, זמינות למשמרות.

**הערות לטרגוט:** גילאים 21–30, קריית מלאכי, גדרה, יבנה, אשדוד, קריית גת, רחובות, באר טוביה ובני עי"ש. כדאי לבנות קהלים לפי אירועי חיים ("סיום שירות צבאי", אם זמין) ולפי מונחי חיפוש (`עבודה לחיילים משוחררים`, `משרה מועדפת`, `מאבטח חמוש`, `אבטחה עם נשק`).

## בנייה מחדש

```bash
npm install                                  # gsap + fonts (Fontsource)
node render.cjs land 60 0.25 30.25           # port / sq likewise → out/raw_<aspect>.mp4
python3 audio/sfx.py audio && audio/mix.sh   # → audio/mix.wav
```
הרינדור דטרמיניסטי: `window.seek(t)` מצייר את הפריים המדויק. הלכידה נעשית ב־60fps ומתמזגת ל־30fps, כך שנוצר טשטוש תנועה, ונוספת גרעיניות פילם ב־ffmpeg.
לתצוגה בדפדפן פותחים את `index.html?a=land&play=1`.
