# סרטון Demand Gen – צוות 3 מיגון

סרטון קולנועי של 30 שניות ליצירת לידים לשירותי מיגון (מצלמות, אזעקה, מוקד 24/7, סיירים).
הסרטון מגיע בשני פורמטים: `build/team3_demandgen_16x9.mp4` (1920×1080) ו־`build/team3_demandgen_9x16.mp4` (1080×1920, ל־Shorts).

## תמונות אמיתיות מהאתר
התמונות של המוקד, הסיירים והאופנוענים נטענות מ־`assets/`. אם קובץ חסר, הסצנה מוצגת בגרסת שרטוט טכני.
```bash
./fetch_assets.sh   # מוריד את התמונות מ-team3.co.il
./build.sh          # מייצר מחדש את המוזיקה ואת שני הסרטונים
```

## קבצים
- `index.html` – הקומפוזיציה (SVG שרטוט, טיפוגרפיה קינטית, HUD, גריין, letterbox, flash/shake על הביט). הפונקציה `seek(t)` דטרמיניסטית.
- `music.py` – פסקול סינתטי (drone, braam, risers, impacts, bass ostinato, תופים) על אותו גריד ביטים.
- `render.js` – רינדור פריים־אחר־פריים עם Playwright ו־ffmpeg (H.264 + AAC, ‎-14 LUFS).
